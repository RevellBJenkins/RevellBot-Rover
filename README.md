# RevellBot Rover  
A personal autonomous differential drive rover designed as a long term project to build robotics and embedded systems skills.  
This repository documents the full engineering process: planning, wiring, firmware development, testing, and later ESP32 and ROS2 integration.

## 🚀 Project Purpose
This rover is my hands on platform for learning:
• motor control (PWM and direction logic)  
• sensor integration (encoders, ultrasonic, ToF)  
• robotics behaviors and state machines  
• embedded C++ on Arduino and ESP32  
• PlatformIO workflow and code organization  
• long term robotics development processes  
• version control and documentation practices  

The goal is not only to build a rover, but to build engineering discipline.

## 📌 Milestone Roadmap
1. Motor Subsystem  
2. Wheel Encoders  
3. Dead Reckoning  
4. Obstacle Sensing  
5. Reactive Avoidance Logic  
6. Finite State Machine  
7. ESP32 Port on PlatformIO  
8. Advanced Sensors (IMU, ToF)  
9. Navigation Behaviors  
10. ROS2 Integration  

Each milestone will be documented in the docs folder.
